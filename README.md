How It Works-
User writes text in the textarea 📄

Select a voice (optional) from the dropdown 🔊

Click "Speak" button 🖱️

AI reads aloud the text using the Web Speech API 🎙️
 Language Selector: Let users pick different languages
 Pause/Resume Button: Add controls for better user experience
 Download as Audio: Convert text to an MP3 file for downloading
 Supports different voices & languages
